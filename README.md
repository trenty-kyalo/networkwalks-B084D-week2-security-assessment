**Assessment:** PM1 – Website Footprinting & Reconnaissance | PM5 – Network Scanning

## Project Overview

This repository contains my Week 2 cybersecurity coursework, focusing on website footprinting and reconnaissance, as well as local network discovery and scanning.

The practical activities were conducted using Kali Linux and its security assessment tools.

## Project Modules

### PM1 – Website Footprinting & Reconnaissance

Target: `networkwalks.com`

Tools used:
- WHOIS
- WhatWeb
- Nslookup
- cURL
- WAFW00F
- DNSRecon

The module involved gathering publicly available domain, DNS, web technology, and security-related information.

### PM5 – Network Scanning

Network assessed: `192.168.100.0/24`

Tools used:
- Nmap
- Zenmap
- ARP discovery

The module involved identifying active devices on my local Wi-Fi network, examining discovered hosts, and generating a network topology diagram.
